# Custom Themes

Importable theme add-ons for Oksskolten. These are **not** built-in themes — they live
outside `src/` on purpose, so this fork stays fully mergeable with the upstream repository.

## Installing a theme

1. Open **Settings → Appearance → Custom Themes**
2. Click **Import** and paste the content of the theme's `.json` file
3. Select the theme in the theme grid

Custom themes are stored in your user preferences (server-side), not in the codebase.

## Themes

| File | Name | Notes |
|---|---|---|
| `le-monde.json` | Le Monde | Editorial newspaper look inspired by the Le Monde app. Near-black dark mode with steel-blue accent; warm paper-white light mode with elevated cards. |

## Recommended pairing (Le Monde)

For the full editorial feel, set the article font to a serif in
**Settings → Appearance → Article Font** (e.g. **Lora** or **Merriweather**) —
it applies to both article list titles and the reader view.
