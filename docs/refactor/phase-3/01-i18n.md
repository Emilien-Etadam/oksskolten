# 01 — `src/i18n/`: the dictionary split by domain

Read `00-context.md` first.

## Goal

`src/lib/i18n.ts` is 1,112 lines: a `dict` of 729 keys (`'prefix.name': { ja, en, zh }`)
plus 60 lines of runtime (`Locale`, `useI18n`, `translate`, `LocaleContext`,
`isMessageKey`, `errorCodeMap`). Split the dictionary into one file per key
prefix group and keep the runtime as is. **No behaviour change**: same keys,
same strings, same `MessageKey` union, same `t()` output.

## Layout

```
src/i18n/
  index.ts             the runtime, moved verbatim from src/lib/i18n.ts lines 1–5 and 1053–1112,
                       importing `dict` from './messages/index.js'
  index.test.ts        was src/lib/i18n.test.ts
  messages/
    index.ts           export const dict = { ...common, ...reading, … } as const
    common.ts          header, sidebar, error, toast, confirm, date, about, hint, home, command, search
    reading.ts         article, articles, comments, frontpage, recommended, stories, translate, summary
    feeds.ts           feeds, feedError, category, modal, refresh, metrics
    intelligence.ts    rules, smart, interests
    chat.ts            chat, suggestion
    auth.ts            login, setup, password
    settings.ts        settings, provider, integration, ollama, vllm, openai, gemini, googleTranslate, deepl, github, imageStorage, themeJson
```

Every key prefix in the dictionary is in exactly one line above (the prefix is
the part before the first dot; `grep -oE "^\s+'[a-zA-Z]+\." src/lib/i18n.ts | sort -u`
lists them all, 45 prefixes). If you find one that is not, put it in `common.ts`
and say so in the commit body.

## How to split without losing a key

1. Write a throwaway script (not committed) that reads `src/lib/i18n.ts`,
   extracts every `'key': { … },` entry with its preceding `// comment` lines,
   and writes each into the target file by prefix, **keeping the entries in
   their original relative order** and the comments attached to the first key
   that follows them. Hand-splitting 729 lines is how keys get lost.
2. Each message file is `export const <name> = { … } as const` with no
   imports except `APP_NAME` where `header.title` needs it (import it from
   `../index.js`; check this does not create a cycle at module-evaluation
   time: `index.ts` imports `messages/index.js` which imports `common.ts`
   which imports `APP_NAME` from `index.ts` — that is a cycle. Move
   `APP_NAME` to `src/i18n/app-name.ts` and re-export it from `index.ts` so
   existing importers of `APP_NAME` keep working).
3. `messages/index.ts` spreads the seven objects into one `dict` **`as const`**.
   `type MessageKey = keyof typeof dict` in `index.ts` must still be the
   literal union of all keys (spreading `as const` objects keeps literal keys;
   `npx tsc --noEmit` on a file that does `const k: MessageKey = 'article.markAsRead'`
   proves it, and a wrong key must be a type error).
4. Duplicate keys across files would silently overwrite each other in the
   spread. Add to `index.test.ts` a test that asserts the sum of
   `Object.keys(<file>).length` over the seven files equals
   `Object.keys(dict).length`, and one that asserts `Object.keys(dict).length === 729`
   (update the number if a key was added between now and then; say so).

## Importers

83 files import from `lib/i18n` (`useI18n`, `type TranslateFn`, `translate`,
`APP_NAME`, `isMessageKey`, `LocaleContext`, `type Locale`). Update every one
to `@/i18n` (alias, see `00-context.md`); `sed` over `src/` then
`npx tsc --noEmit` is the right tool. No façade at `src/lib/i18n.ts`: delete
it.

`scripts/lint-no-japanese.ts` allowlists `src/lib/i18n.ts` and
`src/lib/i18n.test.ts` (lines 12–14). Replace those two entries with
`/^src\/i18n\/messages\//` and `/^src\/i18n\/index\.test\.ts$/`.
`src/lib/demo/i18n.ts` stays where it is (demo strings, separate dictionary).

## Acceptance

- `ls src/lib/i18n.ts src/lib/i18n.test.ts` → both missing.
- `grep -rn "lib/i18n" src scripts --include=*.ts --include=*.tsx` → empty.
- The key-count tests pass; `npx tsc --noEmit` fails if you temporarily use a
  misspelt key (try it, then revert).
- `npx tsx scripts/lint-no-japanese.ts` passes.
- Typecheck, lint, both vitest projects, `npm run build` green.
